# AGENTS.md

## Pre-requisitos

- Repositorio en GitHub creado y con acceso
- `gh` CLI configurado (`gh auth login`)
- Node.js instalado

## Comandos

- `npm start` - arrancar servidor local
- `npm test` - correr tests
- `npm run build` - construir para producción

## Reglas

- Dependencies se agregan en `package.json`. No agregar sin preguntar.
- Commitear después de cada cambio significativo.
- Los issues de GitHub son el backlog canónico.

## Documentos

- `_docs/planteamiento.md` - checklist de planeación antes de hackaton
- `_docs/process.md` - cómo se organiza el trabajo
- `_docs/task-template.md` - template para grooming de issues
- `_docs/team/pm.md` - rol del Product Manager
- `_docs/team/engineer.md` - rol del Software Engineer
- `_docs/team/qa.md` - rol del QA Engineer
